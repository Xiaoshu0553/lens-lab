# 平台完整功能逻辑与设计说明书

本目录保存当前大学生版本的说明书、正文来源、目录页码和生成脚本。研究对象仅限18–25岁、当前在读的专科生和本科生；年龄区间为18–20、21–23、24–25岁，三个区间共用一份30题问卷和同一校园任务。

| 内容 | 当前版本或用途 |
| --- | --- |
| 研究设计 | `university-v1` |
| 统一候选问卷 | `student-literacy-v1-30` |
| 校园任务 | `student-campus-v1`，四个私事实情景 |
| 公共基础提示 | `answer-dialogue-v6` |
| A组额外澄清提示 | `clarify-dialogue-v4` |
| 合成展示批次 | `student-126-20261022-v1`，126条模拟记录 |

S组与A组使用相同模型、公共资料和完整对话历史；A组额外加入主动澄清提示。真实模型直接回答当前问题，`pilot/live`不由独立澄清模块替代回复。`demo`的离线规则模拟另行标记。合成展示记录、研究者试跑和真实参与者数据分别保存，模拟记录不能用于估计真实干预效应。

## 文件与生成

- `content.md`：说明书正文，保留原有十九章和附录结构。
- `build_document.py`：生成Word文档及两张流程图，所有路径均相对脚本所在目录。
- `page_map.json`：经最终渲染核对的目录页码；正文变更后须重新校正。
- `figures/`：脚本生成的实验闭环图与两组提示流程图。
- `LENS_Lab_评测平台完整功能逻辑与设计说明书.docx`：交付文档。

需要Python 3、`python-docx`和`Pillow`。在有上述依赖的环境中，可从任意工作目录运行：

```bash
python /path/to/lens-lab/docs/manual/build_document.py
```

脚本将文档和流程图写入本目录。绘图优先使用`CJK_FONT`指定的中文字体文件；未指定时依次查找macOS黑体、Linux Noto CJK和Windows微软雅黑。系统没有可用中文字体时，应先安装中文字体并明确指定路径，例如：

```bash
CJK_FONT=/path/to/NotoSansCJK-Regular.ttc python /path/to/lens-lab/docs/manual/build_document.py
```

文档沿用原说明书的A4版式。生成后须渲染并检查每页，核对目录、中文字体、表格和图示；脚本成功运行不代替排版检查。

## 版本与使用边界

本目录只发布当前大学生版说明书。原跨年龄说明书在项目本地工作档案中保留，不作为当前操作或研究口径。历史问卷、任务、数据及其原始快照不按新版重写。

说明书描述功能、流程和解释边界，不是已验证量表、伦理许可或研究效果证明。候选问卷和评分仍需面向目标学生群体进行认知访谈、内容审查和真实预测试。正式分析应遵循预先确定的研究方案，并以实际导出的版本和字段为准。
