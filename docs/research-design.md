# 研究设计与记录说明

本文说明当前系统实现与数据解释边界，不替代预注册、伦理审查、问卷验证或正式统计分析方案。

## 研究范围与准入

当前方案为 `university-v1`，仅面向 **18–25 岁、当前在读的专科生和本科生**。人口学年龄区间为 18–20、21–23、24–25；在读学段为 `college`／`bachelor`。开始前必须勾选年龄与在读确认，后端要求 `student_confirmed=true`。页面自报不等于核验真实学籍，研究者仍需执行招募与纳入流程。

当前随机条件是标准交互与主动澄清交互。年龄及学段是目标群体内的背景变量，不是实验处理；三个年龄区间不使用不同难度或不同任务。规范表达、口语表达等风格没有被随机操纵，现有分组不能直接解释成语言表达差异的因果检验。参与者另填写核查通知／规则的熟悉程度，该自报变量与信息素养前测分开记录。

## 统一问卷与校园任务

三个年龄区间共用 **一份 30 道独立题目的问卷**，版本 `student-literacy-v1-30`。题目覆盖检索、来源与时效、证据判断、规则应用、核验与使用五个领域，每领域 6 题。当前不存在三份年龄适配卷，也不再使用旧跨年龄方案的 9 卷、270 题位、126 种材料口径。

题目采用短句、分行材料和具体对象，提供作答所需信息；最后一项“我暂时不会选”区分个人不确定与结论“资料还不足以判断”。当前为原创候选工具，尚未标定题目难度、信效度或人群适配性。`anchor_score` 仅保留 18 个指定题 ID 的兼容分项，不代表已校准锚题，也不说明与旧跨年龄量表等值。切换当前年龄区间不清空问卷答案。

三个区间共用一套校园共创任务，版本 `student-campus-v1`。虚构申请人陈禾为 21 岁在读本科生，公共规则明确活动仅供 18–25 岁在读专科生和本科生。任务在三个年龄区间保存各自任务 ID，以便匹配人口学记录；正文、公共规则、选项与评分相同，不能把这三个存储 ID 计为三套独立任务。

统一任务有四种私事实情景：`first_3`、`first_1`、`return_3`、`return_1`。它们组合改变每周最多可到场次数（1／3 次）及此前是否获得本项目名额。公共资料保持不变，两项私事实分别影响登记类别和参加安排。模型初始只获得公共背景及资料；私事实由参与者掌握，只有参与者提供后才进入对话。任何组的参与者都可主动补充。

## 分配与两组提示

系统在年龄区间、信息素养得分区间及当前任务版本条件内平衡分配案例情景和标准组／澄清组。年龄分层用于平衡背景，不构成年龄处理。统计还约束设计、问卷、模型配置、运行模式、澄清策略和对应提示词版本，防止不同方案混算。

两组使用相同模型、温度、公共资料和完整对话历史，并接收相同基础提示。标准组没有额外主动澄清要求，模型仍可能自然追问；澄清组在对话前额外收到主动澄清提示，并在每轮请求中保留。该提示要求缺少会改变当前判断的关键事实时，先问一个简短具体的问题；信息充分时直接回答用户的问题；已提供的事实不重复询问；补充后继续作答。不会仅因短句或口语表达触发追问，也没有“两次追问后撤销提示”的限制。

共同基础提示包含相同输出标记约定：模型实际索取缺失个案信息时，以 `【澄清提问】` 开头。这是格式约定，标准组不会因此额外获得“必须主动提问”的要求。后端对两组均识别并剥离标记，动作记录为 `prompt_clarification`，不按组别预设次数为零。

当前策略为 `prompt`；旧配置 `module` 仅兼容映射为 `prompt`，不再启用独立判断模块。`pilot/live` 将当前用户问题与完整历史直接交给模型，模型可解释规则、比较或整合依据、给出有依据的建议，须说明资料未覆盖的内容。模型不接收私有评分、其他情景或用户尚未提供的私事实。`demo` 使用规则模拟回复，不能用于判断真实模型是否执行提示。

模型、基础提示及澄清提示版本保存于会话，升级后应开始新会话，不用新提示续接旧记录。服务报告因 `MODEL_MAX_TOKENS` 上限截断时，本轮返回可重试错误，不保存半截回复，不计有效轮次。当前默认输出上限为 1600。

完成两轮有效回复后可进入决策；默认上限 12 轮、30 分钟，由 `MAX_TURNS` 与 `MAX_MINUTES` 控制。进入决策后不能继续提问。输入框 Enter 发送，Shift+Enter 换行，中文输入法确认不发送；等待回复时不能重复提交。

## 最终选择与评分

参与者从 5 个参加方案和 5 个办理方案中各选一项，两组选项独立随机排列，公开标识不透露内部得分。参加方案最高 80 分，办理方案最高 20 分，合计为 0–100 的候选决策质量分；登记类别、参加安排、办理规则的权重为 40／40／20。

两项私事实各影响最优方案。办理方案独立考查有效期限、办理渠道和材料，不从参加选项直接给出答案。系统另存规则可行与目标满足指标，它们与质量分不同；质量分不等于实际成功率。

评分依据会话开始时冻结的选项和情景。首次提交后不修改选择、分数或结束时间，人工审核不能改写客观得分。错误选项允许同分，不强求五档严格递增。权重、部分分、情景难度及评分合理性均需专家审阅、目标群体试做和敏感性分析。

## 材料版本与数据隔离

| 材料／数据 | 当前版本或用途 |
| --- | --- |
| 研究方案 | `university-v1` |
| 统一问卷 | `student-literacy-v1-30`，30 道独立题目 |
| 统一任务 | `student-campus-v1`，4 个私事实情景 |
| 研究者材料审查 | `student-material-review-v1`，含答案与私事实，仅认证研究者可见 |
| 当前合成批次 | `student-126-20261022-v2`，126 条大学生模拟记录 |
| 浏览器存储 | 新 `lens_university_v1_*` 命名空间，参与者和试跑再隔离 |

任务、选项、评分与私事实以任务会话快照保存；真实前测保存问卷版本及逐题答案，完整题文由版本化源码和发布材料保存，尚无逐会话问卷题文快照。旧作答、分数、任务快照及对话不得按新材料重写。旧跨年龄模块和历史审查仅供兼容／归档，不进入当前参与者材料、当前下载目录或新方案结果。

当前真实模型试跑使用独立 `university-data/lens.sqlite3`；当前合成展示使用 `university-showcase-data/showcase.sqlite3`。旧 `data/`、`showcase-data/`、600 条来源包和 V1 展示数据应先转存到服务器外私有备份并核验，再从服务器移除；不导入新库。服务器仅保留两个当前学生运行数据目录，Compose 不再挂载旧来源目录。同一服务内也按版本、运行模式、模型配置和记录来源筛选。`demo`／`pilot`／`live` 及真实／合成来源不得合并作实证推断。

## 时间与过程计数

| 字段 | 定义与限制 |
| --- | --- |
| `task_completion_seconds` | 前测完成并创建任务会话，到首次接受最终提交的经过秒数 |
| `dialogue_elapsed_seconds` | 创建会话到进入决策的经过秒数 |
| `decision_elapsed_seconds` | 进入决策到最终提交的经过秒数 |
| `pretest_time_seconds` | 当前没有问卷答题起点，保持空值，不补造时点 |
| `ai_clarification_count` | 按已保存澄清动作复算；当前模型依据输出标记识别，两组均计数 |
| `ai_guidance_count` | 已保存 AI 消息中任务引导动作次数 |
| `ai_prompt_count` | 主动澄清与任务引导之和，按消息动作复算 |

任务时长包括阅读、模型等待、中途停留和提交前反馈，并非活跃操作时间；刷新恢复不重新计时，缺少时点时留空。原始时点采用带时区 UTC，后台显示北京时间。回复服务耗时包含规则答复处理，不能当成纯模型推理时间或调用次数。

澄清标记可能漏标或误用，次数不能直接视为全部真实追问；应离线审核正文和动作。旧 `module_clarification` 动作保留历史计数，不与当前提示干预混为同一实现。一般资料回复、问候、事实确认与资料未覆盖回复不计提示次数。过程提醒从实际答案向量及对话派生，例如“不确定作答 X 题”；不按组别或低分制造提醒，不自动排除样本，也不证明作答无效。

## 导出与纳入

所有导出均需管理员认证。

| 接口 | 内容 |
| --- | --- |
| `/api/admin/export?kind=raw&format=csv` | 常用原始记录 |
| `/api/admin/export?kind=analysis&format=json` | 当前版本中问卷完整且客观题已提交的普通研究记录 |
| `/api/admin/dialogue-export?format=json` | 与完成记录使用同一连接编号的有序对话 |
| `/api/admin/archive-export?kind=raw&format=json` | 内部完整归档，含会话 ID、来源、快照、事件及审核历史 |
| `/api/admin/synthetic-datasets` | 仅当前大学生合成批次的可下载清单 |
| `/api/admin/synthetic-export?file=csv` | 当前批次合成导出，不是受试者研究导出 |

研究导出的 `kind` 为 `raw`／`analysis`，`format` 为 `csv`／`json`。字段按人口信息、实验条件、30 题答案、结果、过程及时间排列；CSV 使用中文表头，JSON 使用英文键，以实际导出表头及版本为准。

常用页面和导出通过永久 `record_id` 连接，新记录追加编号，删除后不复用。独立对话 JSON 按会话保存，CSV 按消息逐行；内部 ID 与来源保留在受认证保护的归档中。分析纳入由当前版本、完整问卷及最终客观提交自动确定，不依赖人工审核状态。未提交的结果与完成时长为 `null`／空白，不能按零分处理。

图表人数实际是会话记录数。系统不核验参与者身份或去重，同一人可重复开始；不能把记录数宣称为独立参与者人数。

## 研究者试跑与 126 条合成展示

`/admin/preview` 使用独立浏览器存储，记录为 `researcher_preview`，不占普通参与者分配名额，不进入普通逐题分析或常规导出。普通研究记录为 `participant`；无法确认来源的旧记录可保留 `unclassified`，不得自动改为参与者。

`pilot` 调用真实模型，但其 `is_demo` 可能仍标记材料／阶段，判断时应同时看 `run_mode`。合成展示使用 `SHOWCASE_MODE=1`、`demo` 和专用 `showcase.sqlite3`，初始化前检查数据库隔离；普通启动不填充样本。

当前 V2 批次使用 `student-independent-simulation-v2` 生成器和 `student-authored-dialogue-v2` 对话模板，共 126 条完成记录，三个年龄区间各 42 条、S／A 各 63 条；ID 为 `SYNTH-STUDENT-V2-{age}-{001..042}`。仅前测答案和决策在独立分组前生成，不按目标均分调节。人工对话另预设 A 组分两轮分别询问本项目名额和每周到场次数，补齐后继续回答原问题并逐条提供 5 张线索；S 组由用户主动补充两事实后取得 3 张线索。两组分别为 8 轮和 5 轮，每个揭示事件均有对应资料正文及时间戳；A／S 总计 315／189 张线索是人工过程假设，不是模型实测效应。

`manifest.evidence_policy_is_simulated_assumption=true`、`evidence_cards_per_record={S:3,A:5}`，实际模型调用为 0。真实前测耗时与 `synthetic_pretest_time_seconds` 均为空，模型实测延迟也为空；任务时点仍标记模拟。它们不是旧 600 条或 V1 数据的改名，不是招募样本，正式 `platform_analysis_eligible=0`。五项常用导出直接连接同一 V2 数据库；合成来源接口保留材料、清单和说明供核验，页面不重复列出下载目录。模拟分数、线索差、时点和过程提醒均不能支持真实参与者效应。

## 逐题分析与组间比较

后台提供答对率及 95% Wilson 区间、不确定率、题余分相关、高低组区分差、干扰项选择率和 KR20。小样本、同分重叠与零方差需单独解释；无数据时不宣称区分度高，不按后续任务成绩筛选前测作答，也不自动删题。

任务比较先在同情景内计算，再固定等权汇总，情景缺组时不填造结果。组均值差不是同一个人的前后提高。正式推断可在预先确定的模型中检验连续素养与澄清条件的交互，并控制案例和人口学背景，不预设澄清必然有效、必然缩小差距或只对某一素养组有益。

当前没有真实大学生结果，不能用合成展示给出效应结论。公开真实结果前仍需认知访谈、逐题与差异项审查、目标群体内测量性质和情景等值检验，并处理重复参与、缺失、退出、样本量及多重比较。

## 参与者保护与运行边界

页面不要求姓名、学号或电话，参与者可退出并请求删除当前会话。对话仍可能含主动输入的个人信息，部署者需说明数据处理、留存、删除和访问范围。远程模型会收到对话，应在同意流程中说明具体服务与处理范围。

管理员网页登录使用有期限的 HttpOnly Cookie，脚本可用 Basic 认证。部署应启用 HTTPS 和随机凭证。单进程 SQLite 适合本地与小规模预测试，扩大收集前需验证并发、备份、恢复与访问控制。软件测试通过不等于工具已验证、获伦理许可或可直接正式招募。
